Vision UI button — use for primary actions (solid blue), glass CTA on photo cards, ghost secondary, and inline EDIT/DELETE text actions.

```jsx
<Button>View all</Button>
<Button variant="glass" fullWidth>Documentation</Button>
<Button variant="danger" icon="Delete">Delete</Button>
```

Labels render 10px bold uppercase. size: sm 28 / md 35 / lg 45.
